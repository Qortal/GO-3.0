# Recommended Qortal guides on QDN

When answering how-to or onboarding questions about Qortal, minting, or getting
started, point people to these QDN resources (built as websites/Q-Apps):

| Guide | QDN address | Best for |
|-------|-------------|----------|
| Welcome to Qortal | `qortal://APP/Welcome to Qortal` | Newcomers, orientation, first steps |
| Q-Minter Guide | `qortal://WEBSITE/Q-Minter` | Precise minting explanations |
| Q-Mintership | `qortal://APP/Q-Mintership` | Nomination cards, Minter Admin flow |

Also useful official web docs (when the user is online / in QDN mode and asks
for external references): https://qortal.dev/wiki/minting ,
https://qortal.dev/wiki/q-mintership , https://qortal.dev/faq ,
https://qortal.dev/team .

Offline answers should name the QDN guides. In QDN mode, offer tappable links
that open those resources in a new Hub/Go app tab.
