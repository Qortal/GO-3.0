# Q-Apps directory (curated)

Short directory of widely used Qortal Q-Apps / websites. Prefer exact names.
When the user asks “what is &lt;app&gt;”, answer from this list and invite them to
open the QDN tab (QDN mode shows avatar + open button).

## Q-Assets (APP)

Asset issuance, management, trading, and documentation for **native** Qortal
assets (not EVM tokens). QORT is asset ID 0 and is created by minting /
consensus; other assets are issued by an account with a full max supply and
are typically used like ownership / stock-like instruments. Repo:
gitea.qortal.org/crowetic/Q-Assets

## Q-Tube (APP)

Primary decentralized video platform — upload, watch, tip, share on QDN.

## Ear-Bump (APP)

Music: upload, play, share audio and playlists on QDN.

## Q-Mail (APP)

Encrypted mail between Qortal identities.

## Q-Blog (APP)

Decentralized blogging and mini web builder.

## Q-Share (APP)

Publish / browse / download files on QDN.

## Q-Shop (APP)

Community marketplace for goods and services (related: Q-Mart on QDN).

## Q-Fund (APP)

Decentralized crowdfunding with QORT.

## Q-Support (APP)

Submit Core / UI / Q-App issues to developers.

## Q-Trade (APP)

Cross-chain QORT trading UI (atomic / AT trades, no custodial exchange).

## Q-Wallets (APP)

## Q-Node (APP)

## Q-Manager (APP)

## Q-Search (APP)
