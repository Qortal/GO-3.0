## Q: What can I do in Qortal Hub?

A: Qortal Hub is the desktop app for Qortal on Windows, macOS and Linux. In one window you can create or unlock your account, send and receive QORT, chat in Q-Chat groups and direct messages, make voice calls, open Q-Apps and websites from QDN, publish your own apps, and set up and control your own Qortal Core node, including minting.

## Q: Which Qortal Hub file should I download for my computer?

A: Get Hub from the Downloads page on qortal.dev, which has a button for Windows, Mac and Linux plus a Linux (Script) installer; every release, including older ones, is also on the Releases page of the Qortal-Hub project on GitHub. The files are Qortal-Hub-Setup-win64.exe for Windows, Qortal-Hub-Setup-macOS.dmg for a Mac, Qortal-Hub.AppImage or Qortal-Hub-Setup.deb for a normal 64-bit Linux PC, and Qortal-Hub-arm64.AppImage for 64-bit ARM such as a Raspberry Pi.

## Q: How do I install Qortal Hub on Windows?

A: 1. On qortal.dev Downloads, click Windows to get Qortal-Hub-Setup-win64.exe.
2. Open it from your Downloads folder and click Yes when Windows asks to allow changes.
3. Keep the suggested install location unless you have a reason to change it, and click Install.
4. When it finishes, leave Run Qortal Hub ticked and click Finish.
If SmartScreen warns you, choose More info, then Run anyway.

## Q: How do I install Qortal Hub on a Mac?

A: 1. On qortal.dev Downloads, click Mac to get Qortal-Hub-Setup-macOS.dmg.
2. Open the .dmg and drag Qortal Hub into your Applications folder.
3. Eject the installer disk: right-click it on the Desktop and choose Eject.
4. Open Spotlight, type Qortal and choose Qortal Hub. If a popup appears, click Open.
If macOS still blocks it, right-click the app in Finder and choose Open.

## Q: How do I install Qortal Hub on Linux?

Or download Qortal-Hub.AppImage (Qortal-Hub-arm64.AppImage on ARM), allow it to run as a program and start it. On Debian or Ubuntu you can also install Qortal-Hub-Setup.deb.

## Q: Do I need Qortal Core installed to use Hub?

A: No. Hub can connect to a public node, so you can create an account and look around straight away. Running your own Core is optional but recommended: it gives full decentralized access, faster downloads and keeps your data under your control, and you need it to mint and to publish to QDN, because the public node takes no uploads. Hub can download, install and start Core for you from its Set up Qortal Core window.

## Q: How do I create a new account in Qortal Hub?

A: 1. On the Enter Qortal screen click Create account.
2. Choose a wallet password, type it again, leave Save account in Hub ticked and click Continue.
3. Your seedphrase appears; you can reveal, copy or export it. Click Create account.
4. Click Backup wallet and save the encrypted backup file. Enter Hub only unlocks after that.
5. Click Enter Hub. Everything happens on your computer, with no sign-up server.

## Q: What is the wallet password in Qortal Hub?

A: It is the password you choose when you create or import an account. It encrypts the account saved on this computer and your backup file, and Hub asks for it to unlock, to send QORT and to reveal your private key. There is no password reset: if you forget it, import the account again from your seedphrase and choose a new password.

Java is only for Qortal Core: on Windows Hub runs the official Core installer, and on Linux and macOS, if no Java is found, Hub downloads its own Java 17 into your home folder when it sets up Core. ## Q: What does Block do in Hub's User Search?

A: Block adds the person's name to your node's blocked names and their address to its blocked addresses. Blocking an address affects how your node handles their transactions, and blocking a name hides their data across Hub. Unblock reverses it. Blocking needs your own node; on a public node the button is unavailable.
